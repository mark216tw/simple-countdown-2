# 簡單倒數 v1.3.0

此版本強化倒數識別色，讓進行中的倒數更容易辨識，並提供更多顏色選擇。

## 主要變更

- 首頁上方的進行中倒數卡片改用該倒數的識別色。
- 卡片文字、狀態、圖示與剩餘時間會依識別色亮度自動切換黑色或白色，維持清楚對比。
- 倒數識別色色盤由 12 色增加至 24 色。
- 新增深紅、琥珀、萊姆、翡翠、湖水藍、深藍、薰衣草、洋紅、玫瑰、陶土、金色與炭灰色。

## 安裝需求

- Android 7.0（API 24）以上。
- Package ID：`com.example.simplecountdown`。
