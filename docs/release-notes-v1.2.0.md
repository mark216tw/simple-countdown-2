# 簡單倒數 v1.2.0

此版本更新 App 名稱與 launcher icon，讓產品名稱更簡潔、圖示更容易辨識。

## 主要變更

- App 顯示名稱由「簡單倒數2」調整為「簡單倒數」。
- 首頁標題改為讀取 Android `app_name` 資源，避免顯示名稱不一致。
- Launcher icon 改為原創沙漏圖示，使用珊瑚紅、莓果紅與亮紫色漸層背景。
- 沙漏採象牙白外框與金黃色流沙，核心圖案位於中央 `66 x 66 dp` 安全區。
- Adaptive Icon 畫布為 `108 x 108 dp`，前景內容保持在中央 `72 x 72 dp` 裁切區內。
- 新增 Android 13 themed icon 使用的單色沙漏圖示。

## 安裝需求

- Android 7.0（API 24）以上。
- Package ID：`com.example.simplecountdown`。
