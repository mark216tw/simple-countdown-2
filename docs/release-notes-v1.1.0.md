# 簡單倒數 v1.1.0

此版本改善外觀設定、倒數鈴響選項與預設排序體驗。

## 主要變更

- 新增珊瑚紅、活力橙、薄荷綠、晴空藍、亮紫色及莓果紅六種 App 主題色。
- 主題色與深色模式點擊後立即套用並儲存。
- Android 系統導覽列會同步主題的淺色或深色模式。
- 鈴響時間改為無聲、10 秒、30 秒、1 分鐘、5 分鐘及不自動停止。
- 移除獨立的完成提示音開關。
- 改善預設卡片拖曳時的手指同步與換位動畫。
- 預設識別色增加至 12 種，並放大倒數時間字型。

## 安裝需求

- Android 7.0（API 24）以上。
- Package ID：`com.example.simplecountdown`。
